# ⏰ 定时提醒助手 (Timer Reminder)

Windows 桌面定时提醒工具，帮助保持健康工作习惯、按时完成报告。

## ✨ 功能

### 🏃 健康提醒（起立放松 + 喝水）

- **起立放松**：可配置间隔（默认 60 分钟）
- **喝水提醒**：可配置间隔（默认 30 分钟）
- 周一至周五 + 当月最后一个周六

**工作时段（周一至周五可分别设置，另加月末周六）**：

| 周一 | 周二 | 周三 | 周四 | 周五 | 月末周六 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 09:00–20:30 | 09:00–20:30 | 09:00–17:30 | 09:00–20:30 | 09:00–17:30 | 09:00–18:30 |

- 午休免打扰 12:00–14:00 + 晚餐免打扰 17:30–18:00

### 📝 报告提醒

**普通周**（不含月末最后一个周六）：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 日报 20:00 | 日报 20:00 | 日报 17:00 | 日报 20:00 | 周报 17:00 | — |

**末周六周**（含当月最后一个周六的那周）：

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 日报 20:00 | 日报 20:00 | 日报 17:00 | 日报 20:00 | 日报 17:00 | 周报 18:00 |

> 周五改发日报、周六发周报。周六是本月最后一个工作日。末周六周中的周五日报时间和周六周报时间可在设置页修改。

### 🔕 免打扰

- **定时免打扰**：午休 + 晚餐时段自动暂停健康提醒
- **手动免打扰**：托盘右键 → 30 分钟 / 1 小时 / 2 小时 / 直到下班
- 到时自动恢复，托盘提示显示剩余时间

### ⚙️ 设置面板

所有时间统一在「通用设置」标签页管理：工作时段、提醒间隔、免打扰时段、报告时间、弹窗关闭秒数。健康/报告标签页管理开关和文字。修改即时保存。

### 🔒 单实例

重复启动会通知已有实例弹出设置窗口，不会开启多个进程。

## 🚀 快速开始

### 直接运行（推荐）

从 [Releases](https://github.com/Ch1hiro0814/Timer/releases) 下载 `TimerReminder.exe`，双击即可。首次运行会自动弹出设置窗口。

### 开机自启

将 `TimerReminder.exe` 快捷方式放入：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

### 从源码运行

```bash
git clone https://github.com/Ch1hiro0814/Timer.git
cd Timer
pip install -r requirements.txt
python main.py
```

## 📦 打包

```bash
build.bat
# 输出: dist/TimerReminder.exe
```

## 🛠 技术栈

- Python 3.11+ + Flask + PyWebView 内嵌设置页
- pystray + Pillow 系统托盘
- PyInstaller 单文件打包

## 📁 项目结构

```
├── main.py              # 入口：单实例锁 → 配置 → 调度器 → 托盘线程 → mainloop
├── config.py            # 配置管理（JSON 持久化）
├── scheduler.py         # 后台调度引擎（30s 轮询、按天工作时段、末周六逻辑）
├── popup.py             # 弹窗组件（居中置顶、倒计时、延迟提醒）
├── tray_manager.py      # 系统托盘菜单、免打扰管理
├── settings_window.py   # 设置页本地 Web 服务
├── web_ui/              # HTML/CSS/JS 设置前端
├── utils.py             # 工作日判断、末周六检测、时间匹配、单实例锁
├── config.json          # 默认配置
├── build.bat            # 一键打包脚本
├── version_info.txt     # exe 版本信息
└── requirements.txt     # Python 依赖
```

## 🔧 配置

配置保存在 `%APPDATA%\TimerReminder\config.json`，所有设置均可通过 GUI 修改。
